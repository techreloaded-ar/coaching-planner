## Mandatory Conflict Search

Before asking the client anything and before writing any spec, search for prior decisions that the request may contradict. `archetipo wiki search` is not sufficient. Do all of the following and report the outcome to the client in your first message, quoting file and line:

1. Grep `{config.paths.prd}` for the key terms of the request (the entity, the action, its synonyms) and for every requirement identifier (`RF-`, `RNF-`) whose text mentions them.
2. Grep `{config.paths.wiki}/decisions/` and `{config.paths.wiki}/references/` for the same terms.
3. Read every match in context.

If a documented decision, requirement, or constraint conflicts with the request, state the conflict explicitly to the client, ask whether the earlier decision is superseded, and record the answer in the spec. If nothing conflicts, say so explicitly ("no prior decision found on ...") with the files searched.
