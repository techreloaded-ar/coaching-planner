# Plan for US-038

<!-- archetipo:plan-body -->

## Soluzione tecnica

La spec introduce una pagina di dettaglio del collaboratore nel back office, raggiungibile dalla riga dell'elenco Collaboratori, con lo storico delle attività raggruppato per mese solare in ordine decrescente.

**Approccio per layer:**

- **Dominio (calcolo puro, ADR calcoli-puri):** nuova funzione pura `raggruppaAttivitaPerMese` in `src/domain/consuntivi/index.ts` che riceve righe serializzabili (`data` YYYY-MM-DD, `clienteRagioneSociale`, `offertaCodice`, `offertaDescrizione`, `ore`, `fatturabile`, `nota`) e produce gruppi mese ordinati per token `YYYY-MM` decrescente, ognuno con righe ordinate per data crescente e totali `oreTotali` e `giornateTotali` calcolati con `ORE_PER_GIORNATA = 8` (ADR giornata-otto-ore).
- **Query applicativa:** nuova funzione `storicoAttivitaCollaboratore(collaboratoreId)` in `src/lib/collaboratori.ts`, riservata all'amministratore via `richiediRuoloApi("AMMINISTRATORE")` come le funzioni esistenti del file; legge tutte le `RigaAttivita` del collaboratore con `include` di cliente e offerta, ordinate per `data asc, createdAt asc` (stesso pattern di `src/lib/attivita.ts`).
- **Pagina:** nuova rotta server component `src/app/(back-office)/anagrafiche/collaboratori/[id]/page.tsx` — `richiediRuolo("AMMINISTRATORE")`, caricamento profilo via `collaboratorePerId` (esistente) con `notFound()` se assente, poi storico via nuova query e raggruppamento con la funzione pura.
