#### US-001: Scaffold dell'applicazione Next.js e ambiente di sviluppo

**Epic:** EP-000 | **Priorità:** HIGH | **Punti:** 2 | **Stato:** TODO
**Bloccata da:** -

**Storia Utente**
Come sviluppatore del progetto Coaching Planner,
voglio un'applicazione Next.js (App Router) con TypeScript, Tailwind CSS e la struttura di cartelle prevista dall'architettura,
così da poter sviluppare tutte le funzionalità successive su una base coerente e avviabile in locale.

**Dimostrazione**
Dopo l'implementazione di questa spec, uno sviluppatore può clonare il repository, installare le dipendenze, avviare l'applicazione in locale e vedere una pagina iniziale funzionante; il linter gira senza errori.

**Criteri di Accettazione**
- [ ] L'applicazione Next.js 15 con TypeScript si avvia in locale e mostra una pagina iniziale
- [ ] La struttura di cartelle prevista è presente: aree front office e back office, modulo di dominio, lib e components
- [ ] Lint configurato e in esecuzione senza errori sul codice di partenza
- [ ] Le variabili d'ambiente sono gestite tramite file locale non committato, con un file di esempio versionato
